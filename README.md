# Image Edit (Using Tensor)

Best for highlighting your technical skills and architectural choices to recruiters and peers. 💡 🚀 

Just built an interactive Image Manipulation Web App using Flask and PyTorch!

Ever wanted to manipulate images at a pixel and regional level directly from your browser? I created a lightweight web application that bridges the gap between Python's powerful tensor processing and interactive front-end controls.

## Key Features:

1) 🎛️ Pixel-Level Control: Use Radio buttons to target and dynamically shift R, G, B channels across the entire image.
2) 📐 Polygon Region Selection: Click to draw custom polygons on the canvas to isolate and modify specific areas.
3) 🔄 State Management (Undo/Redo): Fully tracking changes so you can revert either to the original state or the last modified state.
4) 💾 Smart Download: Download your modified image at any point in time.

## The Tech Stack:

1) Backend: Flask (Python) handles the routing and state management.
2) ML/Data Engine: PyTorch converts images into tensors for fast, matrix-based color transformations.
3) Frontend: HTML5 Canvas & JavaScript for tracking mouse coordinates, drawing polygons, and handling live UI updates.
